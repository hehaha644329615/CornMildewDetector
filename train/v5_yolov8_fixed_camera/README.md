# v5：固定相机方案（YOLOv8 + 硬件标准化）

本版本核心目标：通过**统一拍照距离与角度**，消除早期版本中因拍摄条件不一致带来的输入噪声，让模型专注学习霉变特征。

## 版本定位

| 项目 | 说明 |
|------|------|
| 模型 | YOLOv8n |
| 类别 | 2 类（light_mold / heavy_mold） |
| 核心改进 | 固定相机采集，统一输入分布 |
| mAP50 | **0.920**（相对 v4 的 0.293 大幅提升） |
| 训练轮数 | 50 epoch |
| 图像尺寸 | 640×640 |

## 硬件方案

- 采集容器：60×60cm 簸箕（或同尺寸标准容器）
- 手机支架：固定于容器正上方，保证镜头垂直向下
- 拍照要求：
  - 距离、角度全程统一
  - 每次倒入约一斤玉米
  - 均匀摊成单层，尽量无重叠

> 说明：训练与推理必须使用同一套固定采集条件，否则精度会明显下降。

## 数据采集流程

1. 每次称取约一斤玉米粒
2. 倒入簸箕/容器中，均匀摊平（单层、无重叠）
3. 随机混入不同数量的轻度、重度霉变样本
4. 手机固定在支架上拍摄
5. 按比例划分 train/val 后，再分别做数据增强

本版本先用较小规模数据验证「固定采集」路径的可行性，确认有效后再在 v6 扩大数据量。

## 霉变率计算

预先统计一斤玉米的平均粒数：

1. 称 100g 玉米 → 数粒数
2. 重复多次，按正态分布取均值 \(\mu\)
3. 一斤约等于 \(5\mu\) 粒

预测时：

$$
\text{霉变率} = \frac{\text{轻度个数} + \text{重度个数}}{5\mu}
$$

- 分子：模型检出的轻度 + 重度霉变框数量
- 分母：固定预统计均值，不依赖检测健康粒

> 注：后续上线版（v6 / App）进一步改为  
> \(\dfrac{x_1/2 + x_2}{5\mu}\)（轻度按损失一半重量计算），以更贴近饲料厂实际加工逻辑。

## 实验结果摘要

| 指标 | v4 | v5 | 变化 |
|------|----|----|------|
| 整体 mAP50 | 0.293 | **0.920** | ↑ +0.627 |
| light_mold AP50 | 0.128 | **0.865** | ↑ 显著 |
| heavy_mold AP50 | 0.458 | **0.975** | ↑ 显著 |
| F1 | 0.34 | **0.88** | ↑ +0.54 |

## 核心结论

1. **硬件标准化是精度飞跃的关键**  
   输入分布被锁定后，模型不再需要同时学习「不同拍照方式」，学习难度大幅下降。

2. **数据质量（一致性）优先于数据数量**  
   少量固定视角样本，效果远好于大量视角混乱的网络图片。

3. **系统思维**  
   完整方案 = 硬件采集标准 + 模型算法 + 工程部署，三者缺一不可。
