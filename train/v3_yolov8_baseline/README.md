# v3：YOLOv8n 基线 — 轻量化转折

从 Faster R-CNN 切换到 YOLOv8n，并去掉健康类别，改为二分类，验证轻量化模型在本项目上的可行性。

## 版本定位

| 项目 | 说明 |
|------|------|
| 模型 | YOLOv8n |
| 类别 | 2 类（light_mold / heavy_mold），移除健康 |
| 数据 | 与 v1/v2 同源，仅保留霉变标注 |
| mAP50 | **0.277** |
| 模型大小 | **12 MB**（Faster R-CNN 约 350 MB） |
| 推理速度 | 约 18 FPS（相对两阶段模型大幅提升） |

## 主要改动

1. **框架切换**  
   放弃体积大、速度慢的 Faster R-CNN，改用 YOLOv8n，面向手机端实时推理。

2. **任务简化为二分类**  
   去掉健康类别，只检测轻度 / 重度霉变，避免健康与轻度高度重叠带来的决策困难。

3. **仍使用早期网络收集数据**  
   拍照距离、角度、背景尚未统一，数据泄露问题也尚未系统修复。

## 实验结果摘要

| 指标 | v2 (Faster R-CNN) | v3 (YOLOv8n) | 变化 |
|------|-------------------|--------------|------|
| 整体 mAP50 | ~0.263 | **0.277** | ↑ 略升 |
| light_mold AP50 | — | 0.090 | 仍偏弱 |
| heavy_mold AP50 | — | 0.464 | 明显更好 |
| 模型大小 | ~350 MB | **12 MB** | ↓ 约 97% |

重度霉变明显好于轻度；背景虚警仍较明显。

## 发现的问题

1. **轻度霉变依旧是短板**  
   与背景 / 正常粒差异小，AP 很低。

2. **数据泄露**  
   仍存在「先增强后划分」问题，验证指标参考价值受限，在 v4 中正式修复。

3. **输入质量未改善**  
   距离、角度、背景不统一，限制了上限。

## 核心结论

1. YOLOv8n 在精度相当的前提下，体积和速度远优于 Faster R-CNN，更适合端侧。
2. 二分类方向正确，但数据质量仍是瓶颈。
3. 下一版优先：**修复数据泄露 + 加入空背景负样本**（见 v4）。
