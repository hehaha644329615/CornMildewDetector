# v4：YOLOv8n 优化 — 修复数据泄露 + 加入背景图

在 v3 基础上，重点解决**数据泄露**和**背景虚警**两个问题。

## 版本定位

| 项目 | 说明 |
|------|------|
| 模型 | YOLOv8n |
| 类别 | 2 类（light_mold / heavy_mold） |
| 核心改进 | 先划分后增强；加入空背景负样本 |
| mAP50 | **0.293**（v3 为 0.277） |
| 图像尺寸 | 640×640 |

> 说明：本版本仍未做硬件标准化，mAP 提升有限。精度突破到 0.90+ 发生在 v5（固定相机）。

## 主要改动

### 1. 修复数据泄露

- **问题**：v3 采用「先增强后划分」，同一张原图的不同增强版本同时进入 train 和 val
- **修复**：改为「先按原图划分 train/val/test，再分别增强」
- 保证验证集与训练集在图片层面完全隔离

### 2. 加入空背景负样本

- **问题**：模型易把地面黑点、阴影、纸盒纹理误判为霉变
- **修复**：在训练集中加入纯背景图（空纸盒/空桌面等），标注为空
- 帮助模型建立清晰的「背景」概念

## 实验结果摘要

| 指标 | v3 | v4 | 变化 |
|------|----|----|------|
| 整体 mAP50 | 0.277 | **0.293** | ↑ +0.016 |
| light_mold AP50 | 0.090 | **0.128** | ↑ +0.038 |
| heavy_mold AP50 | 0.464 | 0.458 | 基本持平 |

轻度霉变有所改善，但整体仍受输入质量（拍照距离/角度不一致）限制。

## 核心结论

1. 数据划分顺序是基本功：先划分后增强，否则指标会虚高
2. 空背景负样本能有效降低虚警
3. 在非标准化拍摄数据上，单纯调参 / 加 epoch 收益已经很小  
   → 下一阶段必须转向**硬件标准化采集**（见 v5）
