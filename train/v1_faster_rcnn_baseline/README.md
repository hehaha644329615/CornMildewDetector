# v1：Faster R-CNN Baseline

项目起点。使用 Faster R-CNN + ResNet50-FPN 做三分类目标检测，在网络收集的霉变玉米数据上建立第一版基线。

## 版本定位

| 项目 | 说明 |
|------|------|
| 模型 | Faster R-CNN + ResNet50-FPN |
| 类别 | 3 类（健康 / 轻度霉变 / 重度霉变） |
| 数据 | 网络收集图片为主，约 210 张原图，增强后约 800 张 |
| mAP50 | **~0.242** |
| 标注策略 | 全量标注霉变 + 抽样/半自动标注健康 |

## 实验配置

- 置信度阈值：0.5
- IoU 匹配阈值：0.45
- 霉变率计算（当时）：  
  \(\text{霉变率} = \dfrac{\text{轻度} + \text{重度}}{\text{健康} + \text{轻度} + \text{重度}}\)

## 主要结果

| 真实类别 | 召回率 | 主要问题 |
|----------|--------|----------|
| 健康 | 62.4% | 约 1/3 被当成背景忽略 |
| 轻度霉变 | **仅 6.6%** | 大量漏检为背景，或误判为重度 |
| 重度霉变 | 55.9% | 相对最好，但仍有较多漏检 |

轻度霉变几乎「看不见」：363 个真实样本中仅 24 个正确检出，漏检率约 93.4%。

## 问题分析

### 1. 拍照条件完全未统一

未考虑拍摄距离、透视角度、光照差异。同一类玉米在不同图里尺度、背景差异极大，模型被迫同时学习「怎么拍」和「什么是霉变」。

### 2. 数据划分与增强顺序错误

早期采用「先增强再划分」的方式，验证集中出现训练集的「双胞胎」图，造成**数据泄露**。  
表面指标参考价值下降，调参多次也难有实质提升。

### 3. 背景噪声是最大干扰源

- 有的在水泥地上拍，有的打开蛇皮袋拍
- 霉点是黑色，水泥缝、堆叠阴影也是黑的
- 强光下缝隙、袋面图案发白，玉米粒尾部也偏白  

模型很容易把霉点或玉米尾部与背景混淆。训练集中又缺乏干净的空背景负样本，背景概念建立不起来。

### 4. 健康类别标注不完整

健康粒只标注了过半数，未标注区域在训练中被当作背景。  
轻度霉变与健康外观接近，于是也被一起「推」进背景区域，召回极低。

> 可用本目录下的可视化脚本对比验证集上的真实框与预测框（如 `GT&Pred_vision.py`、`gt_vs_pred.jpg`），直观看到漏检与误检分布。
